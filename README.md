# Scoop Bucket for conduitAI

[Scoop](https://scoop.sh) bucket for [conduitAI](https://conduitai.app) CLI tools on Windows.

## Install

```powershell
scoop bucket add conduitai https://github.com/conduit-technologies/scoop-bucket
scoop install conduitai
```

## Update

```powershell
scoop update conduitai
```

## Available Packages

| Package | Description | Version |
|---------|-------------|---------|
| `conduitai` | CLI for searching, installing, and managing AI tools | 0.6.0 |

## Other Platforms

- **macOS/Linux:** `brew tap conduit-technologies/tap && brew install conduitai`
- **npm (all platforms):** `npm install -g @conduitai-app/cli`
